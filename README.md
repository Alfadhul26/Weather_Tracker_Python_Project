# Weather Tracker Python Project
A weather tracking app using python and streamlit

## Problem Statement
Developed for weather enthusiasts who want a simple application to track local weather observations and analyze weather patterns.

## Website Functions
The user can do the following:
1. Record a new weather observation
2. View weather statistics
3. Search observations by date
4. View all observations

## Additional Function
1. Display temperature trends using line graph
2. Filtering observations by month or season
3. Predict tomorrow's weather based on fetched API data
4. Compare current year data with previous years

## Data API Integration:
- Fetch live current weather and short-term forecasts for the user's city directly from the API and save those observations.
- AI Meteorologist Summary: Send the past 7 days of weather data to an LLM to generate a natural-language summary, outfit suggestions, or local activity recommendations based on upcoming conditions.
